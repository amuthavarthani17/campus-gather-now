# CampusConnect Hub

Build a complete College Event Management Website – CampusConnect using Lovable Cloud backend.

Features:

Student signup/login, profile and dashboard

Browse, search and filter events by category

Event details with poster, date, time, venue, rules and seats

Online event registration with duplicate-registration prevention

Registration confirmation and My Registrations

Admin login with protected dashboard

Admin CRUD for events, categories, students and registrations

Dashboard stats for events, students and registrations

Role-based access control and secure routes

Database: Users, Events, Categories, Registrations with proper relationships.

UI: Modern, clean, professional college style; blue/white theme; responsive mobile + desktop; attractive event cards; clear CTAs; good spacing and typography; include loading, empty and error states.

Use realistic sample data. Make everything functional, polished and responsive.

This project was built with [Lovable](https://lovable.dev).

**Live app**: https://campus-gather-now.lovable.app
